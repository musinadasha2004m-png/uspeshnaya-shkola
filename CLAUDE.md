# Проект: сайт «Успешная школа»

Онлайн-школа полного цикла: от подготовки к школе до сдачи ЕГЭ и
профориентации. Сайт — не каталог услуг, а инструмент доверия родителей.

## Тон и правила бренда (кратко)

- Главная эмоция, которую должен вызывать сайт у родителя — **спокойствие
  и доверие**, не тревога и не давление.
- Никогда не продаём через страх («ребёнок не сдаст экзамен», «вы теряете
  время»). Никогда не обещаем результат без усилий.
- Текст простой, честный, без канцелярита и без кричащих обещаний.
- Полная версия философии и позиционирования бренда — в файле
  `docs/project-bible-summary.md` (используй только если нужно
  сформулировать НОВЫЙ текст; для готовых блоков сайта — см. ниже).

## САМОЕ ВАЖНОЕ ПРАВИЛО ДЛЯ КОНТЕНТА

Все тексты для существующих блоков сайта уже утверждены и лежат в
`/content/*.md`. **Никогда не переписывай, не сокращай и не «улучшай»**
этот текст без явной просьбы. Просто вёрстай то, что там написано.
Если для нового блока/страницы текста ещё нет — спрашивай, а не
придумывай сам.

## Дизайн-система

Все цвета, шрифты и размеры — в `/design/tokens.css`. Не используй
цвета или размеры «на глаз» по скриншоту — бери значения из этого файла.
Референс вёрстки — `/design/homepage-reference.png` (скриншот
утверждённого макета первого экрана) и общий стиль-гайд
`/design/moodboard.png`.

Шрифт: **Manrope** (Google Fonts).

## Структура контента

```
content/
  00-header.md          — шапка, меню, контакты соцсетей
  01-hero.md             — первый экран (H1, подзаголовок, статистика, кнопки)
  02-directions.md       — блок «Выберите программу» (карточки направлений)
  02.2-community.md      — блок про соцсети школы
  03-trust.md            — блок «Почему нам доверяют» (6 карточек)
  04-process.md          — блок «Как проходит обучение» (6 шагов)
  05-promo.md            — акционный блок
  06-testimonials.md     — блок «Успехи учеников» (кейсы + отзывы)
  07-faq-form.md         — блок FAQ + форма заявки
```

Названия файлов соответствуют порядку блоков на главной странице сверху
вниз — собирай секции в этом порядке, одну за раз.

## Стек (уточни/зафиксируй перед началом)

_Впиши сюда выбранный стек, например:_
- Vite + React + Tailwind CSS
- Форма заявки: [сервис/эндпоинт]
- Хостинг: [Vercel / Netlify / другое]

## Как работать над секциями

1. Бери один файл из `content/` за раз.
2. Смотри соответствующий кусок `design/homepage-reference.png`.
3. Верстай компонент, используя токены из `design/tokens.css`.
4. Не переходи к следующей секции, пока не свёрстана текущая и не
   сверена визуально.
